# FutureTech

Адаптивный многостраничный сайт, посвященный технологиям будущего. Реализован на чистом HTML, SASS и JavaScript практически без использования сторонних библиотек.

В проекте используется модульная структура SASS с разделением на компоненты, переменные и миксины. JavaScript отвечает за обработку событий и динамическое обновление контента. Верстка выполнена по методологии Dekstop First с использованием Flexbox и Grid. Код соответствует стандартам семантической разметки и accessibility

**Технологии**: HTML5, SASS (SCSS), JavaScript.
